# WeatherNow - Final VS Code Project

## Setup
1. Get an OpenWeather API key.
2. Open `backend/.env` and replace `YOUR_API_KEY_HERE`.
3. Open VS Code terminal:

```bash
cd backend
npm install
npm start
```

4. Open `frontend/index.html` with VS Code Live Server.

Backend runs on `http://localhost:5000`.

Features: city search, current location, responsive dashboard, current weather, details, 5-day forecast, 12-hour forecast, recent searches, Celsius/Fahrenheit and dark mode.
